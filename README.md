# java-lotto-precourse

### 요구사항
사용자에게 구입 금액을 입력 받아, 개수만큼 로또를 랜덤 생성하고,   
당첨 번호, 보너스 번호를 입력 받아, 로또 당첨 여부와 수익률 계산


### 동작
1. 사용자에게 구입 금액 입력 요청 메세지를 출력한다.
2. 구입 금액을 입력 받는다. ← 입력값 검사 실행
3. 구입 금액으로 로또 개수를 계산한다.
4. 로또 개수만큼 로또를 생성한다. ← 로또 값 검증
5. 로또 개수와 로또 결과를 사용자에게 출력한다.

6. 사용자에게 당첨 번호 입력 요청 메세지를 출력한다.
7. 당첨 번호를 입력 받는다. ← 입력값 검사 실행 
8. 사용자에게 보너스 번호 입력 요청 메세지를 출력한다.
9. 보너스 번호를 입력 받는다. ← 입력값 검사 실행

10. 당첨번호를 , 를 기준으로 분리해, 로또를 만든다. ← 리스트 검중 실행
11. 각 로또별로 당첨 여부를 계산한다.
12. 수익률을 계산한다.

13. 결과를 사용자에게 출력한다.
